## 🛠️ Multiverse Operations Guide

The compiler and runtime environment are bundled into a single file named `athing.py`. It requires Python 3 to simulate the multidimensional physics.

### Step 1: Initialize the Multiverse
Execute the script from your terminal or press the **Run** button directly within your IDE (such as Visual Studio Code):
```bash
python athing.py
```

### Step 2: Write Source Code
*   Upon launch, the script checks for a local file named `code.10d`. If absent, it generates a standard baseline universe automatically.
*   The script will trigger a system subprocess to launch your operating system's native default text editor (e.g., Notepad on Windows, TextEdit on macOS).
*   The terminal execution will temporarily pause while the editor window remains open. Write your commands sequentially inside double quotes.

### Step 3: Save and Compile Reality
*   Save your modifications within the text editor (`Ctrl+S` or `Cmd+S`).
*   **Close the text editor window completely.**
*   The Python runtime will resume automatically, parse the spacetime syntax string, evaluate all structural cell shifts, and output the final numeric state of each modified dimension across all timelines in the terminal.
